# AI agents and agent orchestration

The current overview lives in the [AI & Automation category](../../categories/ai-agents.md), generated from the authoritative catalog.

The six upstream projects are OpenClaw, Hermes Agent, Agent Zero, OpenHands, Paperclip and Buzz. Their roles differ significantly; none has been installation-tested or security-audited by this repository. Read upstream instructions and use isolated environments for computer-use or shell-capable agents.
