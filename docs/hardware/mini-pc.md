# Mini PC / headless server notes

For a low-maintenance Linux mini PC, compare a conventional Debian installation with an atomic/image-based operating system. The best choice depends on the workload, required drivers, maintenance model and target hardware.

- Use the [distribution notes](../distributions/index.md) for OS families.
- Use [Cockpit](../server-management/cockpit.md) for native host management.
- Use [remote-browser choices](../remote-access/browser-in-browser.md) when headless access to GUI applications is needed.
- Check whether an option requires containers: not every remote-browser project offers a native service installation.

**No benchmark claims are made.** RAM requirements, CPU features, idle power and application performance must be measured or sourced before ranking candidates.
