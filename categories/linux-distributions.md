## Highlighted starting points

- [Debian](https://www.debian.org/) - Community-developed Linux distribution suitable for desktop and server use.
- [Rhino Linux](https://github.com/rhino-linux) - Ubuntu-based rolling-release Linux distribution using Pacstall and an XFCE-based desktop.
- [Universal Blue](https://universal-blue.org/) - Fedora-based bootc/OCI image-building ecosystem, not a standalone Linux distribution.
