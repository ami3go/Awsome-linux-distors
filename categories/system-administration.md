## Highlighted starting points

- [Cockpit](https://github.com/cockpit-project/cockpit) - Linux server administration through a web console.

## Research and alternatives

- [OSTree Updates](https://github.com/cockpit-project/cockpit-ostree) - OSTree/immutable OS updates.
- [Package Manager](https://github.com/hatlabs/cockpit-package-manager) - PackageKit package browser.
- [Packages](https://github.com/openSUSE/cockpit-packages) - Package install/remove.
- [Pacman](https://github.com/pfeifferj/cockpit-pacman) - Arch Linux package management.
- [Repositories](https://github.com/openSUSE/cockpit-repos) - SUSE package repositories.
- [RHEL Subscription Manager](https://github.com/cockpit-project/subscription-manager-cockpit) - RHEL subscriptions; RHEL-specific.
- [Software Updates](https://github.com/cockpit-project/cockpit) - PackageKit-based updates.
- [SUSE Subscriptions](https://github.com/openSUSE/cockpit-subscriptions) - SUSE subscriptions.
- [System Overview](https://github.com/cockpit-project/cockpit) - Core services, logs, users and system overview; normally bundled.
- [Transactional Updates](https://github.com/openSUSE/cockpit-tukit) - SUSE transactional OS updates.

For Cockpit integration and package caveats, see the [Cockpit cross-index](../integrations/cockpit/README.md).
