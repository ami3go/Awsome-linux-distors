System diagnostics, health metrics and monitoring resources.

Generated from the structured YAML catalog. Changes belong in `data/`, not in this page. **Highlighted** means editorial visibility, not installation, security or hardware validation.

## Highlighted starting points

- [PCP Metrics](https://github.com/cockpit-project/cockpit) - Performance Co-Pilot time series and metric history.
- [Sensors](https://github.com/ocristopfer/cockpit-sensors) - Lm-sensors hardware readings.

## Research and alternatives

- [Cockpit Top](https://github.com/ismetozalp/ctop) - Btop-like system/process monitor.
- [Diagnostic Reports](https://github.com/cockpit-project/cockpit) - System diagnostic collection.
- [Kernel Dump](https://github.com/cockpit-project/cockpit) - Kdump configuration.
- [ROS 2 Diagnostics](https://github.com/clearpathrobotics/cockpit-ros2-diagnostics) - ROS2 diagnostics.
- [Temperature History](https://github.com/cgillinger/cockpit_temp) - PCP/lm-sensors temperature charts; hobby project.
- [Terminal Trove — top alternatives](https://terminaltrove.com/categories/top/) - Curated directory of terminal-based process and system monitoring alternatives.

For Cockpit integration and package caveats, see the [Cockpit cross-index](../integrations/cockpit/README.md).
