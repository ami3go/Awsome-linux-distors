Disks, files, sharing, backup and transfer tools.

Generated from the structured YAML catalog. Changes belong in `data/`, not in this page. **Highlighted** means editorial visibility, not installation, security or hardware validation.

## Highlighted starting points

- [Cockpit Files](https://github.com/cockpit-project/cockpit-files) - Integrated file manager.
- [Storage](https://github.com/cockpit-project/cockpit) - Partitions, LUKS, RAID, NFS, iSCSI.

## Research and alternatives

- [Awesome Selfhosted — web file managers](https://awesome-selfhosted.net/tags/file-transfer---web-based-file-managers.html) - Directory of browser-based, self-hosted file management projects.
- [Backblaze B2 Backup](https://github.com/rabol/backblaze-b2) - Backblaze B2 backup UI.
- [Benchmark](https://github.com/45Drives/cockpit-benchmark) - Storage benchmarking.
- [Download Superstation](https://github.com/dl-romero/cockpit-download-superstation) - Libtorrent downloader.
- [Explorer](https://github.com/ismetozalp/explorer) - File manager, editors, AI CLI and system tools.
- [File Sharing](https://github.com/45Drives/cockpit-file-sharing) - SMB/NFS and storage sharing.
- [File Sharing (mietzen)](https://github.com/mietzen/cockpit-plugins) - Alternative SMB/NFS sharing; package name overlaps 45Drives.
- [Hangar](https://github.com/ismetozalp/hangar) - Restic backups, scheduling and restore.
- [Manifest](https://github.com/ismetozalp/manifest) - Aria2 downloads including torrents.
- [Navigator](https://github.com/45Drives/cockpit-navigator) - File manager.
- [Plakar Backup](https://github.com/RiddermanR/cockpit-plakar) - Plakar stores, snapshots and scheduled backups.
- [SnapRAID](https://github.com/sloraris/cockpit-snapraid) - SnapRAID monitoring; explicitly beta.
- [ZFS Manager](https://github.com/45Drives/cockpit-zfs) - OpenZFS pools, datasets and snapshots.
- [ZFS Manager (brycelarge)](https://github.com/brycelarge/cockpit-zfs-manager) - Alternate ZFS frontend with optional Sanoid.
- [ZFS Storage (mietzen)](https://github.com/mietzen/cockpit-plugins) - Alternative OpenZFS storage and SMART management.
