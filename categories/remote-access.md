Remote desktops, browsers, code environments and support tools.

Generated from the structured YAML catalog. Changes belong in `data/`, not in this page. **Highlighted** means editorial visibility, not installation, security or hardware validation.

## Highlighted starting points

- [KasmVNC](https://github.com/kasmtech/KasmVNC) - Web-based remote desktop and application access technology.
- [Xpra HTML5](https://github.com/Xpra-org/xpra-html5) - HTML5 client for forwarding remote Linux application windows.

## Research and alternatives

- [jlesage Docker Firefox](https://github.com/jlesage/docker-firefox) - Firefox container exposing a browser-accessible graphical interface.
- [LinuxServer Chromium](https://github.com/linuxserver/docker-chromium) - Containerized Chromium with a browser-accessible graphical interface.
- [Neko](https://github.com/m1k1o/neko) - Shared browser/desktop sessions streamed with WebRTC.
- [Pilot](https://github.com/ismetozalp/pilot) - Self-hosted RustDesk provisioning and control.
- [VS Code Server (mietzen)](https://github.com/mietzen/cockpit-plugins) - Code-server service and web editor.

For Cockpit integration and package caveats, see the [Cockpit cross-index](../integrations/cockpit/README.md).
